# TouristinBD

A capstone project analyzing Bangladeshi tourism reviews to find tourist preferences
(including niche "long-tail" ones), with a website to chat about them, build itineraries,
and compare destinations.

## What's in this folder right now

- `frontend/index.html` — the clickable demo (Phase 0). Double-click to open in your browser.
  Chat/itinerary/compare tabs still run on fake mock data for now.
- `data/real_reviews_batch1.csv` — first real batch of scraped Google Maps reviews (Phase 1),
  280 reviews across 14 Bangladeshi places.
- `docs/PROGRESS.md` — running checklist of what's done and what's next. Upload this (or the
  whole folder) at the start of future sessions so we pick up where we left off.
